구독 및 결제

구독을 해지하려면?
iOS는 기기의 설정 → Apple ID → 구독, Android는 Play 스토어 → 구독에서 직접 해지하실 수 있습니다. 해지해도 이미 결제한 기간이 끝날 때까지는 Premium 기능을 계속 사용하실 수 있습니다.

기기를 바꿨는데 결제 내역이 보이지 않아요.
구입에 사용한 것과 같은 Apple ID 또는 Google 계정으로 로그인한 뒤, 앱의 설정 → Premium → 구매 복원을 눌러주세요.

환불은 어떻게 받나요?
인앱 결제 환불은 각 스토어를 통해서만 가능합니다. iOS는 reportaproblem.apple.com, Android는 Play 스토어 주문 내역에서 신청해주세요.

평생 이용권도 해지해야 하나요?
아닙니다. 평생 이용권은 1회 결제 상품으로 자동 갱신되지 않습니다.

음원 재생

발음이 재생되지 않아요.
음원은 처음 재생할 때 내려받아 기기에 저장됩니다. 네트워크 상태를 확인해주시고, 그래도 문제가 있으면 설정 → 오프라인 음원 관리에서 저장된 음원을 정리한 뒤 다시 시도해주세요.

데이터를 쓰지 않고 학습하고 싶어요.
설정 → 오프라인 음원 관리에서 레벨별 음원을 미리 내려받아 두시면 이후에는 네트워크 없이 재생됩니다.

학습 데이터

학습 기록은 어디에 저장되나요?
모든 학습 기록은 기기 안에만 저장됩니다. 서버로 전송하거나 계정에 연동하지 않으므로, 앱을 삭제하면 함께 사라집니다.

기록을 초기화하고 싶어요.
설정 → 데이터 초기화에서 모든 학습 진도와 단어장을 삭제할 수 있습니다. 되돌릴 수 없으니 주의해주세요.
